# Archived blog

These files are kept in git but excluded from the site build (see `exclude` in
`_config.yml`). The blog page and post were written for the old al-folio theme.

To restore the blog later:

1. Move the post back into a `_posts/` directory at the repository root.
2. Add a blog page (or recreate `blog-page.md` as `_pages/blog.md`).
3. Update the post's layout and CSS classes for the current site.
4. Remove `archive` from the `exclude` list in `_config.yml`.

The blog is intentionally not part of the current navigation.
